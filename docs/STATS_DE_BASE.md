# Statistiques de base

Version adaptée au jeu : mana commun, pas de déplacement, équipement = skin (seules les armes comptent).

| Statistique | Rôle |
|---|---|
| **Force** | Dégâts de base des attaques physiques ; augmente l'efficacité des compétences d'attaque |
| **Vitalité** | Points de vie de la pièce ; influence la survie face aux attaques |
| **Intelligence** | Dégâts magiques ; efficacité des sorts |
| **Points d'attaque** | Dégâts de base par attaque ; modifiables par l'arme équipée |
| **Résistance** | Réduit les dégâts reçus (physiques et magiques) |
| **Critique** | Chance d'infliger un coup critique ; bonus de dégâts lors d'un critique |

## Ce qui a été retiré par rapport à la première version
La première fiche avait 8 statistiques génériques (Force, Vitalité, Intelligence, Agilité, Endurance, Esprit, Dextérité, Défense). Elle a été revue pour ce jeu :
- **Agilité** (vitesse de déplacement) : supprimée, il n'y a pas de déplacement libre.
- **Mana, Esprit** : supprimés, le mana est commun et ne dépend pas d'une statistique (+1 par tour).
- **Efficacité de compétence** : supprimée, jugée redondante.
- **Potentiel** : supprimé.

## Points à trancher
- **Force et Points d'attaque** se recoupent. Garder Points d'attaque comme valeur finale et Force comme la statistique qui l'augmente, ou n'en garder qu'une.
- Aucune classe n'a encore ses valeurs de statistiques.
- Pistes pour les statistiques spécifiques par classe : Guerrier (maîtrise des armes, rage), Soigneur (puissance de soin), Mage (puissance magique), Assassin (critique, furtivité), Mage noir (magie noire, corruption), Tank (résistance, provocation).
